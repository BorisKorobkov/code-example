1. Web-клиент - небольшой js-код, который находится в \app\modules\socket\classes\Socket::echoScript
   и подключается на каждой странице сайта в views/layouts/main.php.
   Если в конфиге config/params.local.php указаны настройки сокет-сервера, то он...

    1. Коннектится на указанный порт
    2. Представляется (под каким юзером пользователь залогинен в stat)
    3. Постоянно слушает сокет.
    4. Может писать в сокет (emit события). Это пока не используется, но можно запилить свой чат с блэкджеком и шлюхами.
    5. Читает сокет. При получении команды ее выполняет (отображает текст всплывашкой в браузере, удаляя теги в целях безопасности).
       Если пользователь открыл несколько вкладок со stat'ом, то действие будет выполнено во всех этих вкладках.

2. PHP-клиент.

    1. Запускается из консоли или из очереди. Например:
        + `./yii socket/elephant --message="Hello, world"` - отправить событие всем клиентам.
        + Можно отправить не всем, а только определенному клиенту (по его user_users.id). Например, `--userIdTo=229`
        + Можно отправить не всем, а только определенному клиенту (по его user_users.user). Например, `--userTo=korobkov`
        + Можно добавить bootstrap-стиль всплывашки, Например, `--type=danger`. Допустимые значения: warning/success/info/danger. По умолчанию warning.
        + Можно добавить ссылку как абсолютную, так и относительную. Например, `--url=/test`
        + `./yii socket/elephant --message="Борис, посмотри баг" --userTo=korobkov --type=success --url=/test`
    2. Коннектится к сокет-серверу.
    3. Emit события.
    4. Отключается от сокет-сервера и закончивает свою работу.
